📌 1. Despre proiect

LabManager este o aplicație web creată pentru gestionarea activităților dintr-un laborator școlar.

Aplicația permite utilizatorilor să înregistreze experimente, să urmărească materialele disponibile, să noteze rezultatele obținute și să organizeze activitățile desfășurate.

Scopul principal este simplificarea organizării și evidenței activităților de laborator.

🎯 2. Scopul proiectului

Proiectul a fost conceput pentru a demonstra modul în care tehnologiile web pot fi utilizate pentru dezvoltarea unui sistem simplu de administrare.

Prin intermediul aplicației se urmărește:

Organizarea experimentelor.
Evidența materialelor de laborator.
Înregistrarea rezultatelor.
Gestionarea activităților.
Accesarea rapidă a informațiilor.
✨ 3. Funcționalități principale
Funcționalitate	Descriere

📋 Rezultate	Înregistrarea rezultatelor experimentelor.
📅 Activități	Organizarea activităților de laborator.
🔎 Căutare	Identificarea rapidă a experimentelor.
📊 Statistici	Afișarea numărului de experimente și materiale.

🚀 6. Instalare și rulare

Pentru instalarea și utilizarea proiectului, urmați acești pași:

Descărcați proiectul pe calculator.
Deschideți folderul LabManager în Visual Studio Code.
Verificați dacă toate fișierele necesare sunt prezente.
Deschideți fișierul index.html în browser.
Începeți utilizarea aplicației.

Pentru o experiență mai bună, se recomandă utilizarea extensiei Live Server din Visual Studio Code.
